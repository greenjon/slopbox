# SlopBox Manual

For SlopBox 1.1. SlopBox is a music player for Android built on Rockbox's
own code: its codecs, sound processing, settings, database menus and
playlists. This manual describes how to use it on a phone.

It is a modified version of the Rockbox manual. Rockbox's manual covers
dozens of players with different buttons and screens. This one covers a
single target, an Android phone with a touchscreen, and adds the parts that
are SlopBox's own.
